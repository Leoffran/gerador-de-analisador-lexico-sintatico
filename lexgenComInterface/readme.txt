Para usar o programa execute main.py

Para usar o analisador lexico primeiro gere-o escrevendo algo como:
    id: [a-zA-Z]([a-zA-Z]|[0-9])*
    num: [1-9]([0-9])*|0
em definicoes regulares na aba de projeto lexico, em seguida para fazer testes, digite algo como:
    abc 123 teste 456
na parte de codigo fonte na aba de execucao e clique em analise lexica
